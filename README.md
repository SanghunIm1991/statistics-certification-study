# 工学データの妥当性検証のための統計入門

測定値のばらつきは想定の範囲か。部品を変えた前後で、特性値に本当に差が出たのか。外れて見える1点を除いてよいのか。校正曲線の当てはまりを、どこまで信用してよいのか。工学の現場では、こうした判断を毎日のように迫られます。経験と勘で決めてしまいがちなこれらの判断に、統計の道具で根拠を持たせることが、この教材の目的です。

統計の事前の知識はほとんど無い状態から、段階を踏んで学べるように作っています。学ぶ範囲と到達度の物差しとして、統計検定の出題範囲に沿って進み、合格を途中の目標にします。各ステップでは、試験で問われる知識に工学データの例題を添え、「試験の知識」と「現場での使いどころ」を結びつけます。

## 教材の構成

- 概念の説明と手計算の例は Markdown、Python を使う演習（工学の例題・シミュレーション）は Jupyter Notebook に分けています。
- 例題のデータは、乱数のシードを固定して作る模擬データです。生成するコードを Notebook に含めているので、誰でも同じデータを作り直せます。
- 問題はすべて自作です。統計検定の公式テキストや過去問題集の文章・問題は掲載していません。
