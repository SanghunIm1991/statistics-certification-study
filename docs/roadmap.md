# 学習ロードマップ

この教材は、統計の事前の知識がほとんど無い状態から始めて、工学データが妥当かどうかを根拠を持って判断できるようになるまでを、10のステップに分けて進みます。途中の目標は統計検定2級の合格です。2級の出題範囲表に載っている項目は、すべてステップ0〜8のどこかで扱います。最後のステップ9では試験の範囲を離れ、管理図や測定の不確かさなど、工学の現場で使う道具まで進みます。

各ステップは「概念の説明 → 手計算の例 → 工学の例題 → 確認問題」の順に進みます。概念の説明と手計算は Markdown の本文で、Python を使う演習は Jupyter Notebook で扱います。Notebook を動かす環境の作り方は、[環境構築: Python と Notebook の準備](setup.md) にあります。

## 0. 試験について

統計検定は、日本統計学会が公式に認定する検定です。この教材が目標にする2級と、範囲の基礎になる3級の概要は次のとおりです（2026-10-17 に公式サイトで確認）。

| 級 | 方式 | 試験時間・問題数 | 合格の基準 |
|---|---|---|---|
| 2級 | CBT（会場のコンピュータで受験し、通年で実施） | 90分・約35問（4〜5択） | 100点満点で60点以上 |
| 3級 | CBT（通年で実施） | 60分・約30問（4〜5択） | 100点満点で65点以上 |

試験で使える電卓は、四則演算・百分率（%）・平方根（√）の機能を持つ一般的な電卓に限られ、関数電卓は使えません。統計数値表（正規分布表など）は会場で配られます。そこで本教材の手計算の例は、四則・%・√ だけで計算できる手順で書き、対数や指数が要る値は分布表から読み取ります。

3級の範囲は記述統計だけでなく、確率・二項分布と正規分布・母平均と母比率の簡単な推定と検定まで含みます。本教材では3級を受験せず、3級の範囲を2級に向けた基礎として、ステップ0〜7の中で扱います。

> **範囲表の版について**
> 公式サイトの2級のページは範囲表の版を「202409版」と表示していますが、同じページからリンクされている範囲表の PDF の日付は 2018/12/14 です（2026-10-17 時点）。本教材はリンク先の範囲表を基準にしています。受験の前には、公式サイトで最新の範囲表を確かめてください。

## 1. ステップの一覧

| ステップ | 内容 | 工学の例題（予定） |
|---|---|---|
| 0 | **数式の準備**: Σ記号、平均と分散の式の変形、電卓（四則・%・√）での計算の手順、分布表の引き方の入口 | — |
| 1 | **記述統計**: 1変数（データの種類と尺度、度数分布とヒストグラム、分布の形、平均・中央値・最頻値、範囲・四分位範囲・箱ひげ図、分散・標準偏差・変動係数・z得点・歪度・尖度、はずれ値、ローレンツ曲線とジニ係数）と2変数（散布図、共分散、相関係数、擬相関、偏相関、相関行列、クロス表） | センサの繰り返し測定のばらつきの要約、温度とセンサ出力の関係 |
| 2 | **データの活用**: 単回帰の記述（最小二乗法、変動の分解、決定係数、残差プロット、変数変換）、時系列データ（成長率、幾何平均、指数化、移動平均、系列相関とコレログラム、トレンド） | 校正曲線の当てはめ、センサのドリフトを移動平均で見る |
| 3 | **データの集め方**: 観察研究と実験研究、母集団と標本、標本抽出の方法、標本誤差と偏り、フィッシャーの3原則、公的統計などのデータの入手先 | 抜き取り検査の計画、試験片を条件に割り付ける |
| 4 | **確率と確率分布**: 加法定理・乗法定理、条件付き確率、ベイズの定理、確率変数の期待値・分散・共分散、主な確率分布（ベルヌーイ、二項、ポアソン、幾何、一様、指数、正規、2変量正規、超幾何、負の二項） | 不良品の個数（二項・ポアソン）、故障の間隔（指数）、検査で不良と判定されたときに本当に不良である確率（ベイズ） |
| 5 | **標本分布**: 標本平均の期待値と分散、チェビシェフの不等式、大数の法則、中心極限定理、二項分布の正規近似と連続修正、t分布・χ²分布・F分布と分布表 | 平均をとるとばらつきが小さくなることを、シミュレーションで確かめる |
| 6 | **推定**: 点推定（一致性、不偏性）、区間推定（母平均・母分散・母比率・相関係数、2つの母集団の差と比） | 測定値の真の値がどの範囲にあると言えるか |
| 7 | **仮説検定**: p値、第1種・第2種の誤り、検出力、1標本・2標本の平均・分散・比率の検定、適合度検定、独立性の検定 | 部品の変更前後で特性値に差があるか、不良の発生が製造ラインによって違うか |
| 8 | **線形モデル**: 回帰係数の推定と検定、重回帰（偏回帰係数、多重共線性、ダミー変数、自由度調整済み決定係数）、実験計画（処理群と対照群、反復、ブロック化、一元配置分散分析、F比）、統計ソフトウェアの出力の読み方 | 校正曲線をどこまで信用できるか、3つ以上の条件の比較 |
| 9 | **発展（試験の範囲外）**: 正規性の確認、外れ値の検定、管理図、測定の不確かさ、多元配置の実験と直交表 | ステップ1〜8の道具を組み合わせて、1つのデータセットの妥当性を総合的に判断する |

ステップ1は量が多いため、本文を「1-1 1変数データ」と「1-2 2変数データ」の2冊に分け、それぞれに演習の Notebook を付けます。

## 2. 進め方

ステップは番号の順に進みます。前のステップの内容を前提にして書いているため、飛ばさずに読むことをおすすめします。ステップ8を終えたところで2級を受験し、その後にステップ9へ進む流れを想定しています。

各ステップの教材は、作成しだい [README](../README.md) の「読む順番」に加えます。
