# 統計検定を目標にした、工学データの妥当性検証のための段階的な入門教材づくり

## 概要・きっかけ

統計検定に挑戦したい。ただし、統計についての事前の知識はほとんど無い。そこで、何も知らない状態から段階的に学べる入門教材を自分で整備しながら学習する。

- **本当の目的**: 工学分野で、データの妥当性を検証できるようになること（例: 測定値のばらつきが想定内か、2つの条件で結果に本当に差があるか、外れ値を除いてよいか、回帰で求めた関係がどこまで信用できるか、を根拠を持って判断する）
- **試験の位置づけ**: 統計検定の合格は、勉強のモチベーションを保つための中間目標とする。合格そのものが最終目的ではない
- **教材の形**: 試験範囲に沿って段階を踏みつつ、各段階に工学データの例題を付け、「試験で問われる知識」と「工学の現場での使いどころ」を結びつける

統計検定は日本統計学会が公式に認定する検定で、4級〜1級のほか、データサイエンス系・統計調査士などの種別がある。1級以外は CBT 方式（会場の空きしだいで随時受験でき、結果はその場で分かる）とされている（2026-10-17 時点の検索結果による。級の構成・出題範囲・受験方式は着手時に公式サイトで確認する）。

## 評価

- **良い点**
  - 公式テキスト・過去問題集が刊行されており（公式サイトの書籍一覧で確認）、出題範囲表も公開されているとされる（着手時に確認）。学ぶ範囲と到達度の物差しがはっきりしている
  - CBT の級は随時受験できるので、「1段階を終えたら受験する」という区切りを自分で作りやすい
  - 2級の範囲（推定・検定・回帰・分散分析など。Claude の認識で、着手時に出題範囲表で確認する）は、工学データの妥当性検証で日常的に使う道具とかなり重なる
  - 工学の素養（数式・ばらつきへの慣れ）があれば、数学の準備は最小限で済む可能性がある
- **懸念点**
  - 試験対策（公式の暗記・選択問題の解き方）と、実データでの判断力は別物になりやすい。教材の各段階に工学の例題を入れて、両方を往復させる必要がある
  - 工学のデータ検証で重要な道具の一部（測定の不確かさ〈GUM〉、管理図、外れ値の検定、実験計画法など）は、統計検定の中心的な範囲からは外れる、または上の級でしか扱われない可能性がある。試験範囲の外は「発展」として別枠にする
  - 公式テキスト・過去問の内容を教材に写すと著作権上の問題になる。教材は自分の言葉でまとめ、問題は自作する
  - 実務の現場のデータは機密の可能性があり、教材の例題には使えない。模擬データ（乱数で生成）か、利用条件の明確な公開データセットを使う

## 肉付け（学習ロードマップ案）

各ステップは「概念の説明 → 手計算の例 → 工学の例題 → 確認問題（自作）」の順でそろえる。ステップの区切りと級の対応は Claude による案で、着手時に公式の出題範囲表と照らして見直す。

| ステップ | 内容 | 工学の例題（案） | 級の目安 |
|---|---|---|---|
| 0 | 数学の準備: Σ記号、確率の基本（和・積の法則、条件付き確率）、必要なら微分・積分の復習 | — | — |
| 1 | 記述統計: 平均・中央値・分散・標準偏差、ヒストグラム・箱ひげ図、相関係数 | センサの繰り返し測定のばらつきを要約する | 3級相当 |
| 2 | 確率分布: 二項分布・正規分布、期待値と分散、中心極限定理、標本分布（t・χ²・F 分布） | 平均をとるとばらつきが小さくなる理由をシミュレーションで確かめる | 2級 |
| 3 | 推定: 点推定と区間推定（信頼区間） | 測定値の真値がどの範囲にあると言えるか | 2級 |
| 4 | 仮説検定: 帰無仮説・p値、第1種・第2種の誤り、t検定、χ²検定 | 部品変更の前後で特性値に差があるか | 2級 |
| 5 | 回帰分析・分散分析: 単回帰・重回帰、残差の確認、一元配置分散分析 | 校正曲線の当てはまりと残差の妥当性、複数条件の比較 | 2級 |
| 6（発展・試験範囲外を含む） | 工学データの妥当性検証: 正規性の確認、外れ値の扱い、管理図、測定の不確かさ、実験計画法の入口 | ステップ1〜5の道具を組み合わせて、1つのデータセットの妥当性を総合的に判断する | 範囲外／準1級以上の一部 |

- ステップ6は、試験の合格とは切り離した「本来の目的」のための仕上げとして位置づける
- ステップ1は3級の範囲だが、3級は受験せず、基礎の確認に使う（実現方針の分岐点1）
- 受験は2級か1級（どちらにするかは実現方針の分岐点1で未決）。2級を受ける場合、合格したあとに1級へ進むか、ステップ6の工学側を深めるかは、その時点で決める

## 実現性

技術的な難易度は低い。必要なのは学習時間と執筆の手間で、道具は電卓と Python（NumPy・SciPy・matplotlib）で足りる。難しいのは、試験範囲の知識を工学の例題に結びつける教材の設計と、確認問題を自作する手間。

## 実現方針（案）

分岐点1〜4は決定済み（2026-10-17）。残っている未決の点（「着手時に決める」と書いた項目）は着手時に決め、`docs/qa_log.md` に記録する。

- **分岐点1: 学習の始点と受験する級**
  - 選択肢A: 3級 → 2級の順に受ける。小さな成功体験を早く得られる
  - 選択肢B: 2級を最初の目標にし、3級の範囲（記述統計）はステップ1として教材の中で済ませる。工学の検証に必要な推定・検定・回帰に早く届く
  - **決定: 学習は3級の範囲から始めて基礎を確認するが、3級は受験しない。実際に受験するのは2級か1級**（どちらにするかは着手時に決める。2級を経てから1級へ進む形も含む）
  - 注意: 1級は CBT ではなく筆記（PBT）で、年1回（11月）の実施とされている（2026-10-17 時点の検索結果。着手時に公式サイトで確認する）。1級を受ける場合は、受験日から逆算して学習計画を立てる必要がある。2級は CBT で随時受験できる
  - 受験までの計画（受験する級・受験の時期・ステップの配分）の策定は保留とする（ユーザーの方針、2026-10-17）
  - 1級を受ける場合、ステップ5までの範囲では足りない。準1級・1級の出題範囲を確かめ、ステップを追加する（着手時に決める）
- **分岐点2: 計算と可視化の道具**
  - 選択肢A: 電卓と手計算のみ（試験本番に合わせる）
  - 選択肢B: 手計算に加えて Python（NumPy・SciPy・matplotlib）で確かめる。中心極限定理などをシミュレーションで体感でき、実務のデータ処理にもつながる
  - 選択肢C: Excel（実務で手元にあることが多い）
  - 選択肢D: R（統計の専用言語。資料は豊富だが、新しい道具を1つ覚えることになる）
  - **決定: 選択肢B（Python）**。Python とライブラリの版はあらかじめ固定しない。版による制約（ライブラリが対応していない等）が出た場合に、その時点で検討する
  - 試験本番は電卓を使う前提なので、手計算の例は教材に残す（Claude の判断。Python は検算とシミュレーションに使う）
- **分岐点3: 教材の形式**
  - 選択肢A: Markdown（数式と図。差分が読みやすい）
  - 選択肢B: Jupyter Notebook（計算・グラフを実行しながら読める）
  - 選択肢C: 説明は Markdown、計算の演習だけ Notebook に分ける
  - **決定: 選択肢C**。概念の説明・手計算の例は Markdown、Python を使う演習（工学の例題・シミュレーション）は Notebook にする
  - 運用（Claude の案。着手時に見直す）: 1ステップを Markdown 1ファイル＋演習 Notebook（1つ以上）で構成し、Markdown から Notebook へリンクする。Notebook は出力を残してコミットし、コミット前に出力へ個人のパスが残っていないか確認する
- **分岐点4: 例題のデータ**
  - 選択肢A: 乱数で作る模擬データ（条件を自由に設定でき、権利・機密の心配がない）
  - 選択肢B: 利用条件の明確な公開データセット（現実味がある）
  - **決定: 選択肢A（模擬データ）を基本とする**。模擬データでは作るのが難しい例題（現実の測定データ特有のくせが要るもの等）に限り、公開データセットを検討する。その場合は利用条件（ライセンス・再配布の可否）を確かめてから使う
  - 模擬データは乱数のシード（seed）を固定し、生成するコードを Notebook に残して、誰でも同じデータを作り直せるようにする（Claude の判断）
- **作る順番**: ステップ0〜1（3級の範囲で基礎を確認）→ ステップ2〜5 → 受験 → ステップ6。受験する級と、受験をどこに挟むか（1級を受ける場合は、11月の受験日から逆算したステップの追加・配分を含む）は、保留中の受験計画で決める
- 具体的な教材の執筆は、このアイデアファイルを出発点とする実現用のプロジェクト（本リポジトリ）で進める
- **著作権上の注意**: 公式テキスト・過去問題集・参考書の文章や問題を教材に写さない。参考にした範囲は自分の言葉でまとめ直し、出典を書く。過去問は購入して解くだけにする
- **Python の環境**: python.org 版の Python で、プロジェクト専用の仮想環境（venv）を作り（ユーザーの方針、2026-10-17）、パッケージ（NumPy・SciPy・matplotlib・`ipykernel` 等）はそこに入れる。Python 本体とパッケージの導入はユーザー自身が行う

## 類似の既存事例

- 統計検定の公式テキスト・市販の対策本・学習アプリが多数あり、試験対策だけなら教材を自作する必要は薄い
- 工学寄りの統計の資格として QC検定（品質管理検定。管理図・工程能力・実験計画法などを扱う）がある。目的が「工学データの妥当性検証」なので、統計検定2級の後の選択肢、または並行する目標として検討の余地がある（範囲の違いは着手時に確認する）
- **差別化点・示唆**: 試験対策の教材は既にあるので、自作する価値は「試験範囲の各項目に工学の例題を結びつける」ことと、「試験範囲の外にある工学側の道具（ステップ6）まで一本の筋で通す」ことにある
